# PocketTTS Demo App

SwiftUI demo for the PocketTTSCoreML Swift package. Runs fully on-device:
text-to-speech generation via CoreML, sentence-level streaming, and
`AVAudioEngine` playback.

## What you can do

- Pick any of the 21 bundled voices (e.g. *Alba*, *Bill Boerst*, *Peter
  Yearsley*).
- Type text into the editor.
- **Generate** — runs full-utterance generation and stores PCM in memory.
- **Play** — plays the most recent generation.
- **Stream** — splits text at sentence boundaries (using the same
  `split_into_best_sentences` heuristic as the Python reference), then
  generates and plays chunks with one chunk of lookahead. Audible gap only
  appears between chunks if generation is slower than playback (it isn't —
  RTF is ~0.09 on recent iPhones).
- **Stop** — cancels any running task and drops queued chunks.

## Build & run

Prerequisites:
- Xcode 16+ (iOS 18 SDK).
- `xcodegen` (`brew install xcodegen`).
- An iPhone running iOS 18+ and an Apple Developer account for signing.

```bash
cd PocketTTSCoreML/Examples/DemoApp
./prepare_resources.sh            # copies ~490 MB of models + voices
xcodegen generate
open DemoApp.xcodeproj
```

In Xcode:
1. Select the `DemoApp` target.
2. In "Signing & Capabilities", choose your Apple Developer team. The
   project ships with an empty `DEVELOPMENT_TEAM` so this step is required
   locally.
3. Plug in your iPhone, select it as the run destination, and hit Run.

First install pushes a ~490 MB `.ipa` to the device — allow a minute.

## Simulator

The app builds and runs in the iOS Simulator, but the Neural Engine is
unavailable — expect "ANE unavailable" warnings and very slow inference.
Use the simulator to sanity-check UI layout only.

```bash
xcodebuild \
  -project DemoApp.xcodeproj \
  -scheme DemoApp \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro' \
  build
```

## Notes

- Background audio is enabled (`UIBackgroundModes: [audio]`) so streaming
  playback survives backgrounding the app.
- `AVAudioSession` is configured `.playback` / `.spokenAudio` — duck-able
  and respectful of the silent switch defaults.
- First launch recompiles nothing (models ship pre-compiled as
  `.mlmodelc`), but the first CoreML load still takes a few seconds on
  cold cache. A warmup pass runs during the "Warming up…" status.
